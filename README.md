# Soccer Penalty Shootout



This is a Python CLI game where the player plays a penalty shootout against the computer.



## Features



\- Menu system

\- Five penalty rounds

\- Sudden death if the score is tied

\- Three difficulty levels

\- Statistics system

\- Random computer choices

\- Lambda function for checking goals



## Difficulty levels



Level 1: Computer chooses randomly.



Level 2: Computer has a 40% chance to make a smarter choice.



Level 3: Computer has a 65% chance to make a smarter choice.
